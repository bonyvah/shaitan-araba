# Shaitan Araba

A static storefront for a fictional bicycle shop in Bishkek. It exists as a
realistic, controllable **scraping target for [Kuzot](../kuzot)**: a site we
own, whose prices, stock and news we can change at will to test Kuzot's
scraping, change detection, semantic search and AI reports.

The site is in Russian, like most Kyrgyz online shops, with prices in som
(KGS). It sells bicycles **and** accessories, takes orders to a delivery
address (free in Bishkek, carrier tariff elsewhere in Kyrgyzstan), and lists
the shop's hours and contacts.

> Nothing here is a real shop. Orders are not sent anywhere: they stay in the
> browser's `localStorage`. The footer of every page says so.

## Run it

Requirements: Python 3.10+ (standard library only). Docker is optional.

```bash
python3 build.py                                   # src/ → public/
python3 -m http.server 8000 -d public              # http://localhost:8000
```

`public/` is committed, so the site can also be served as-is by any static
host (GitHub Pages, nginx, S3) without running the build.

### Serving it to Kuzot

Kuzot's scraper runs in Docker and can't reach ports on the host (the host
firewall drops them). `docker-compose.yml` runs nginx on Kuzot's network
instead:

```bash
cd ../kuzot && make up                 # creates the kuzot_default network
cd ../shaitan-araba && docker compose up -d
```

- From your browser: <http://localhost:8090>
- From Kuzot (monitored URLs): `http://shaitan-araba/…`, e.g. `http://shaitan-araba/catalog/mtb.html`

nginx serves `public/` live, so after `python3 build.py` the next scrape sees
the new content. There's no need to restart the container.

## Pages

64 pages, all generated from the data files. Every product, price and stock
status is in the HTML itself, so a plain HTTP fetch (Kuzot's static
scraper) sees everything; JavaScript only adds the cart, filters and order form.

| Path | What it is | Kuzot `url_type` |
|---|---|---|
| `/index.html` | Home: hero, category tiles, best sellers, new arrivals, delivery promo, blog, visit us | `homepage` |
| `/catalog/index.html` | All 38 products with filters and sorting | `pricing` |
| `/catalog/bikes.html`, `/catalog/accessories.html` | Bikes / accessories only | `pricing` |
| `/catalog/<category>.html` | One page per category (13): `mtb`, `road`, `city`, `kids`, `ebike`, `folding`, `helmets`, `locks`, `lights`, `pumps`, `bags`, `parts`, `apparel` | `pricing` |
| `/product/<slug>.html` | Product page: price, stock, sizes, specs, delivery cost, related items | `pricing` |
| `/delivery.html` | Delivery tariffs per region, pickup, payment, returns | `pricing` / `docs` |
| `/guide.html` | How to choose a bike, frame size table | `docs` |
| `/blog/index.html`, `/blog/<slug>.html` | Three articles (season prep, routes around Bishkek, e-bikes) | `blog` |
| `/news.html` | Dated shop news: deliveries, price changes, schedule | `changelog` |
| `/contacts.html` | Phone, address, hours, map link | `homepage` |
| `/order.html` | Cart and checkout | — |
| `/404.html`, `/sitemap.xml`, `/robots.txt` | | — |

Machine-readable extras: product pages carry schema.org `Product` JSON-LD
(price in KGS, availability), the home page carries `BicycleStore` JSON-LD
with opening hours, and catalog cards have `data-price`, `data-brand`,
`data-category` and `data-status` attributes.

## Catalog

18 bicycles and 20 accessories in `src/data/catalog.json`:

- **Bikes:** mountain (Merida, Trek, Giant, Stels, Format), road and gravel,
  city, kids (including a balance bike), e-bikes, folding.
- **Accessories:** helmets, locks, lights, pumps, bags and bottles, parts and
  tools (tubes, tires, multitool, kickstand), apparel (gloves, glasses).
- Stock states: `in_stock` (В наличии), `preorder` (Под заказ) and
  `sold_out` (Нет в наличии; shows a "Позвонить" button instead of "В корзину").
- Optional `old_price` shows a strikethrough price and a −N% badge; `new`
  shows a "Новинка" badge; `featured` puts it in "Хиты продаж" on the home page.

Product images are flat SVG drawings generated by `art.py` from each
product's type and `color`. No photos, no external image hosts.

## Ordering and delivery

1. "В корзину" on a card or product page adds the item to a cart in
   `localStorage` (`sa-cart`); the header badge updates on every page and
   across tabs. "Купить сейчас" adds it and opens checkout.
2. `order.html` lists the cart (quantity, remove, sizes), then asks for name,
   phone, **courier or pickup**, region, city, address, comment and payment.
3. Delivery is calculated live from `delivery.regions` in `src/data/site.json`:

   ```
   delivery = bikes × region.bike + (any accessories ? region.small : 0)
   ```

   | Region | Per bike | Accessories (per order) | ETA |
   |---|---|---|---|
   | Бишкек | free | free | 0–1 day |
   | Чуйская | 600 | 200 | 1–2 days |
   | Иссык-Кульская | 1 100 | 300 | 2–3 days |
   | Таласская | 1 200 | 350 | 2–3 days |
   | Нарынская | 1 300 | 350 | 2–4 days |
   | Джалал-Абадская | 1 500 | 400 | 3–4 days |
   | Ошская и г. Ош | 1 500 | 400 | 3–4 days |
   | Баткенская | 1 800 | 450 | 3–5 days |

   Pickup at Паланчиева 6/7 is always free.
4. Submitting validates the form, saves the order to `localStorage`
   (`sa-orders`) with a number like `SA-4K2Q9P`, clears the cart and shows a
   confirmation. There's no backend.

## Changing the site (to test Kuzot)

Everything a scraper sees comes from two JSON files. Edit, run
`python3 build.py`, and trigger a scrape in Kuzot.

| To simulate… | Edit |
|---|---|
| A price change or sale | `price` / `old_price` of a product in `src/data/catalog.json` |
| A product selling out or arriving | `status`: `in_stock` · `preorder` · `sold_out` |
| A new product | Add an object to `products` (needs `slug`, `sku`, `category`, `brand`, `name`, `price`, `status`, `color`, `summary`, `description`, `specs`) |
| A delivery tariff change | `delivery.regions` in `src/data/site.json` |
| New hours, phone or address | `shop` in `src/data/site.json` |
| A news entry or blog post | `news` / `posts` in `src/data/site.json` |

Example, checked end to end against Kuzot: dropping Merida Big.Nine 20 from
49 900 to 46 900 сом and rescraping `catalog/mtb.html` gives a job with
`content_changed: true`. Search with "include removed text" then shows the
old 49 900 passage as removed and the new 46 900 one as current.

## Project layout

```
build.py              renders src/ into public/ (templates live here)
art.py                SVG product and category illustrations
src/data/catalog.json categories and products
src/data/site.json    shop info, delivery tariffs, blog posts, news
src/assets/css/       style.css: the whole design system, no framework
src/assets/js/        main.js (cart, filters, open-now, menu), order.js (checkout)
src/assets/img/       icons.svg sprite, favicon
public/               generated site (committed); don't edit by hand
docker-compose.yml    nginx on Kuzot's Docker network
nginx.conf            static serving + 404 page
```

`build.py` also writes `public/assets/js/data.js`, a compact copy of the
catalog, tariffs and hours for the cart and order form.

## Design notes

- Vanilla HTML/CSS/JS, no frameworks or bundlers. One Google Font (Manrope,
  with Cyrillic); everything else is local.
- Light, white storefront with a single red accent, a dark top bar and footer,
  sticky header with phone and cart. Layout inspired by typical Bishkek bike
  shops such as velo.kg: category tiles, best sellers, delivery promise up
  front, phone always visible.
- Responsive from 360 px: collapsible menu, two-column product grid on phones,
  filters collapse behind a "Фильтры" button.
- Accessible basics: semantic landmarks, skip link, labelled controls,
  visible focus, `prefers-reduced-motion` respected.
